What is Turntable Controller?

Turntable Controller gives a stage revolve named positions, realistic timing and direct rehearsal controls inside SketchUp.

Drag to explore the set, store useful views as pegs, or run a timed change while, for example, listening to rehearsal audio. Pegs and motion settings travel inside the saved model.

One-minute setup

  1. Select the complete revolve group or component.
  2. In Entity Info, enter #Turntable# in the field labelled Instance or Name, depending on SketchUp version. You can also rename the group directly in Outliner.
  3. Open Extensions → Turntable.
  4. Drag the rotation slider or enter an exact angle.
  5. Press + to store the current angle as a named peg. The suggested number prefix keeps cues in creation order; keep it, extend it or delete it.
  6. Save the SketchUp model to retain its Turntable data on disk.

Main controls

SnapMagnetically captures a peg within four screen pixels while dragging. TransitionsAnimates moves instead of jumping directly. × multiplierRuns a preview 1×, 2× or 4× faster. Speed 360°Seconds required for one complete revolution. Motion curveBlends constant-speed linear movement into full acceleration and deceleration. Long wayUses the longer route to the requested angle.

Pegs

  • Click a peg: move to its stored angle.
  • Double-click its marker: jump immediately, bypassing the transition.
  • Double-click or right-click its name: rename it.
  • Right-click its marker: change its stored angle.
  • − then a peg: delete that peg after confirmation.
  • Blank name: displays the automatic fallback name Peg #.

Angles and direction

The working scale is centred on the front: it runs from 180° through 270°, 0° and 90° to 180°. Tick marks occur every 15°, with stronger marks at 45° and 90° intervals.

Without Long way, a transition normally takes the shortest route. Option-click on Mac or Alt-click on Windows also requests the longer route.

Window size

Turntable opens at a compact size intended to align with a narrow SketchUp palette on Mac. The window is freely resizable: make it wider for finer slider control and more separation between closely spaced pegs. Turntable remembers the most recently used size.

Keyboard use

  • Click a number field and use the cursor up/down keys for precise adjustment.
  • Press Return in the degree field to move to the entered angle.
  • Dialog editors open with their text selected so typing replaces the existing value.

Saved with each model

Peg names, peg angles, current angle, rotation speed and motion curve are stored as inconspicuous attributes on the controlled #Turntable# entity. No sidecar file is created.

Different open models keep separate Turntable data. Opening, activating or restoring a model reloads its own settings.

If the controller cannot find the revolve: select the complete group and check that its Instance or Name value is exactly #Turntable#.
